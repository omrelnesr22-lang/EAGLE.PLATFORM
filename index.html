الدرس الأول: التفكير الحاسوبي وحل المشكلات

التفكير الحاسوبي هو أسلوب تفكير منظم يُحاكي طريقة عمل الكمبيوتر في معالجة المشكلات. يعتمد على 4 خطوات أساسية:

  • تحليل المشكلة (Decomposition): تقسيم المشكلة الكبيرة إلى أجزاء صغيرة.
  • التعرف على الأنماط (Pattern Recognition): ملاحظة التشابه بين المشكلات.
  • التجريد (Abstraction): التركيز على المعلومات المهمة وترك التفاصيل غير الضرورية.
  • تصميم الخوارزمية (Algorithm): وضع خطوات محددة ومرتبة للحل.

مثال: جمع رقمين

num1 = int(input('Enter first number: '))
num2 = int(input('Enter second number: '))
sum = num1 + num2
print('Sum =', sum)

ملاحظة: إذا أدخل المستخدم نصاً مثل "خمسة" بدلاً من رقم، سيظهر خطأ ValueError لأن دالة int() لا تستطيع تحويل النصوص إلى أرقام.

الدرس الثاني: خوارزميات الذكاء الاصطناعي

الخوارزمية هي مجموعة من الخطوات المرتبة منطقياً لحل مشكلة معينة. أنواع الخوارزميات:

  • تسلسلية (Sequential): تنفذ خطوة بعد خطوة بترتيب ثابت.
  • شرطية (Conditional): تعتمد على جملة if للتحقق من شرط.
  • تكرارية (Loop): تكرر نفس العملية عدة مرات.
  • البحث (Search): للعثور على عنصر معين.
  • الترتيب (Sorting): لترتيب البيانات.

خوارزميات الذكاء الاصطناعي:

بدلاً من إعطاء البرنامج تعليمات تفصيلية، نقوم بتزويده ببيانات ليتعلم منها:

  • تعلم الآلة (Machine Learning): يتعلم من البيانات ويأخذ قرارات.
  • التعلم العميق (Deep Learning): نوع متطور يستخدم الشبكات العصبية.

مثال: البحث في قائمة

numbers = [3, 7, 10, 5]
target = 10
for num in numbers:
    if num == target:
        print('Found')

الدرس الثالث: السلاسل النصية (Strings) والقوائم (Lists)

السلسلة النصية: مجموعة من الحروف والأرقام والرموز داخل علامتي تنصيص.

القائمة: مجموعة مرتبة من القيم داخل قوسين مربعين [ ].

خصائص السلاسل النصية:

  • len(text): طول النص.
  • text[0]: الوصول لحرف معين (العد يبدأ من 0).
  • text[-1]: الوصول للحرف الأخير.
  • for letter in text:: التكرار على الحروف.
  • "h" in text: البحث داخل النص.
  • text.upper(): تحويل الحروف إلى كبيرة.

عمليات القوائم:

  • names.append("Sara"): إضافة عنصر.
  • names.remove("Ali"): حذف عنصر.
  • for name in names:: التكرار على العناصر.

مثال: فحص قوة كلمة المرور

password = input('Enter password: ')
chars = list(password)
score = 0
if len(chars) >= 8:
    score += 1
for ch in chars:
    if ch.isdigit():
        score += 1
        break

الدرس الرابع: الدوال ذات المعاملات (Functions)

الدالة: مجموعة من التعليمات البرمجية نكتبها مرة واحدة ونستخدمها عدة مرات.

المعاملات (Parameters): قيم نرسلها إلى الدالة لكي تعمل عليها.

شكل الدالة في Python:

def function_name(parameters):
    # code

مثال: حساب مساحة دائرة

def circle_area(radius):
    pi = 3.14
    area = pi * radius * radius
    print("Area =", area)

circle_area(5)

الشرح: def لتعريف الدالة، radius هو المعامل، وعند استدعاء الدالة نعطيها القيمة 5.

الدرس الخامس: معالجة أخطاء مدخلات المستخدم

عند كتابة برنامج، قد يدخل المستخدم بيانات خاطئة (مثل كتابة كلمة بدلاً من رقم). لحل هذه المشكلة نستخدم try و except.

الصيغة العامة:

try:
    # الكود الذي قد يسبب خطأ
except:
    # ماذا نفعل إذا حدث خطأ

مثال: معالجة خطأ القسمة على صفر

try:
    num = int(input("Enter a number: "))
    result = 10 / num
    print(result)
except ValueError:
    print("Please enter numbers only!")
except ZeroDivisionError:
    print("You cannot divide by zero!")

الدرس الأول (الوحدة 2): التنبؤ باستخدام نموذج الذكاء الاصطناعي

البرمجة التقليدية تعتمد على أوامر ثابتة، بينما نموذج الذكاء الاصطناعي يتعلم من البيانات ليتنبأ بالنتائج.

المعادلة الرياضية للنموذج الخطي:

y = w * x + b

  • x: المدخل (عدد ساعات المذاكرة).
  • y: الناتج (الدرجة المتوقعة).
  • w: الوزن (مقدار زيادة الدرجة لكل ساعة).
  • b: الانحياز (الدرجة الأساسية بدون مذاكرة).

مثال بالكود:

def predict_grade(x):
    w = 5
    b = 10
    y = w * x + b
    return y

hours = 3
grade = predict_grade(hours)
print("الدرجة المتوقعة:", grade)

الدرس الثاني (الوحدة 2): الذكاء الاصطناعي وحقوق الملكية الفكرية

عند استخدام تطبيقات الذكاء الاصطناعي، يجب احترام حقوق الملكية الفكرية والخصوصية.

قاعدة المصادر الثلاثة:

  1. المصدر الأول: الذكاء الاصطناعي (للحصول على أفكار أولية).
  2. المصدر الثاني: محرك بحث/موسوعة (للتأكد من المعلومات).
  3. المصدر الثالث: كتاب أو رأي خبير (للتأكد النهائي).

نقاط مهمة في شروط الاستخدام:

  • العمر: معظم التطبيقات تتطلب عمر 13+ سنة.
  • حقوق الملكية: تأكد من ملكية الصورة أو النص المستخدم.
  • حق الحذف: يمكنك حذف سجل المحادثات نهائياً.

تحذير: لا تشارك معلوماتك الشخصية (الاسم الكامل، العنوان، أرقام الهاتف) مع تطبيقات الذكاء الاصطناعي.

الدرس الثالث (الوحدة 2): الوعي السيبراني والألعاب الإلكترونية الخطرة

الألعاب الإلكترونية لها فوائد (تطوير المهارات العقلية، التخطيط، التعاون) ولكن لها مخاطر أيضاً.

مخاطر الألعاب:

  • العنف والألفاظ غير المناسبة.
  • الحيل النفسية (Dark Patterns).
  • الدفع مقابل الفوز (Pay to Win).
  • صناديق الغنائم (Loot Boxes) التي تشبه القمار.
  • العزلة الاجتماعية والمشاك
